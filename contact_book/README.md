# Contact Book

## Description

Contact Book is a simple Python mini-project for saving and managing phone contacts. It runs in the terminal and lets you add, view, search for, and delete contacts. This project is useful for beginners who want to practise Python dictionaries, loops, and user input.

## How to Run

1. Make sure Python is installed on your computer.
2. Open PowerShell or a terminal in the `contact_book` folder.
3. Run this command:

```powershell
python 01_contact_book.py
```

4. Choose an option from the menu and follow the prompts.

## Features

- Add a new contact with a name and phone number
- View all saved contacts
- Search for a contact by name
- Delete a contact by name
- Exit the program safely

## Concepts Used

- Variables
- Dictionaries
- `while` loops
- `if`, `elif`, and `else` statements
- User input with `input()`
- `for` loops
- `print()` statements
