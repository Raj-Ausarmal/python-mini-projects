# To-Do List

This is a small Python project where you can manage your tasks from the terminal.

You can add new tasks, see the tasks you have added, and remove a task when you are finished with it.

## What it does

- Add a new task
- Show all your tasks
- Remove a task
- Exit the program

## Running the program

Open the terminal in this folder and run:

```bash
python 01_todo_list.py
