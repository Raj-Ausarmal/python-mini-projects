# Weather App

A simple Python Weather App that fetches current weather information using the Open-Meteo API.

## Features

- Search weather by city name.
- Display current temperature.
- Show feels-like temperature.
- Display relative humidity.
- Show wind speed.
- Display weather conditions.
- Uses real weather API data.
- No API key required.

## Technologies Used

- Python
- Open-Meteo API
- JSON
- urllib
- Geocoding API

## How to Run

1. Open the terminal in the `weather_app` folder.

2. Run the Python file:

   python weather_app.py

3. Enter a city name when prompted.

Example:

   Enter city name: Aurangabad

The app will display the current weather information.

## API Used

This project uses the Open-Meteo API to fetch weather data.

Website: https://open-meteo.com/
