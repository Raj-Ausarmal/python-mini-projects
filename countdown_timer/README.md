# Countdown Timer

A simple countdown timer made with Python. The user can enter minutes and seconds, and the timer counts down until it reaches zero.

## Features

- Enter minutes and seconds.
- Displays the remaining time in MM:SS format.
- Counts down every second.
- Shows a message when the timer finishes.
- Can be stopped using Ctrl + C.

## Technologies Used

- Python
- time module

## How to Run

Open the terminal in the `countdown_timer` folder and run:

    python countdown_timer.py

Enter the required minutes and seconds when prompted.

Example:

    Enter minutes: 1
    Enter seconds: 30

The timer will start counting down from 01:30.

## How to Stop

Press:

    Ctrl + C

to stop the timer while it is running.
